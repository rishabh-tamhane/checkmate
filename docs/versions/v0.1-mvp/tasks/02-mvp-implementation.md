# MVP Implementation

## Status

Blocked by the
[MVP implementation technical design](../technical-design/02-mvp-implementation.md).

Detailed implementation tasks must be derived from the approved design rather
than used to make architecture or dependency decisions. Do not add or begin MVP
implementation tasks until the design status changes from `Draft` to
`Approved`.

After approval, create ordered tasks that:

- Trace to the included requirements in `../requirements.md`.
- Preserve the module boundaries and policies in the approved design.
- Include focused verification and acceptance evidence.
- Exclude every capability listed as out of scope for v0.1.
